1. Choose 3 Issues (30 min max)

2. Read Issues More Carefully (30 min)
   
   - original description
   - comments from maintainers/team members
   - linked pull requests slash failed attempts
   - labels like "good first issue" or "help wanted"
   - tools/dependencies in CONTRIBUTING.md  

3. Selection Checklist (15 min)
   
   - [ ] Understand
   
   - [ ] Scope 3-4 weeks
   
   - [ ] Skill Match
   
   - [ ] Active and Claimable
   
   - [ ] Context Given
   
   - [ ] Documentation Exists

4. Pick One and Commit (5 min)

5. Fork Chosen Project

6. Comment on the Issue on GitHub

7. Update README and Check-In Form

8. Announce on Slack
